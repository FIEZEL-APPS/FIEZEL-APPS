Cara Install FIEZEL

Pilih perangkatmu di bawah untuk memasang aplikasi FIEZEL langsung ke layar utama:

Android

Panduan Instalasi Android

Rekomendasi

Opsi 1: Pasang Aplikasi Native (.APK)

Unduh berkas instalasi resmi untuk performa grafis dan respon audio terbaik:

Unduh APK Android (.apk)
  1. 1

    Ketuk tombol Unduh APK Android di atas untuk mengunduh fiezel-app-release.apk.

  2. 2

    Buka berkas yang telah selesai diunduh dari bar notifikasi ponsel atau folder Unduhan (Downloads).

  3. 3

    Bila muncul pesan keamanan sumber luar, pilih Setelan lalu aktifkan Izinkan dari sumber ini.

  4. 4

    Ketuk Instal dan buka FIEZEL langsung dari menu aplikasi ponsel Anda.

Opsi 2: Pasang via Google Chrome (Web App / PWA)

Tanpa unduh file APK, hemat memori dan langsung terpasang di layar utama:

  1. 1

    Buka fiezel.my.id/app/ di browser Google Chrome pada ponsel Android Anda.

  2. 2

    Ketuk menu tiga titik di sudut kanan atas Chrome.

  3. 3

    Pilih menu Instal aplikasi (atau Tambahkan ke layar utama).

  4. 4

    Ketuk Instal pada dialog konfirmasi. Ikon FIEZEL akan langsung muncul di beranda ponsel Anda.

iPhone & iPad

Panduan Instalasi iOS (Safari)

  1. 1

    Buka fiezel.my.id/app/ menggunakan browser Safari di iPhone atau iPad Anda.

  2. 2

    Ketuk tombol Bagikan (Share) — ikon kotak dengan panah ke atas di bilah navigasi bawah Safari.

    Ikon kotak dengan tanda panah ke atas.

  3. 3

    Gulir menu ke bawah, lalu pilih opsi Tambah ke Layar Utama (Add to Home Screen).

  4. 4

    Ketuk Tambah di sudut kanan atas. FIEZEL kini siap dibuka dalam mode layar penuh layaknya aplikasi native!

Catatan Khusus iOS: Apple mewajibkan browser bawaan Safari untuk memasang Web App ke Layar Utama. Opsi ini tidak tersedia pada Chrome versi iOS.

Desktop

Panduan Instalasi PC & Laptop

  1. 1

    Buka fiezel.my.id/app/ di Google Chrome atau Microsoft Edge pada Windows, macOS, atau Linux.

  2. 2

    Cari ikon Install di bilah alamat (address bar), tepat di samping kanan URL halaman.

    Ikon berupa layar komputer dengan tanda panah ke bawah.

  3. 3

    Klik ikon tersebut, lalu klik Instal pada dialog konfirmasi.

  4. 4

    FIEZEL langsung terbuka di jendela mandiri tanpa bingkai browser dan tersimpan di menu aplikasi komputer Anda.

Alternatif: Bila ikon install di address bar tidak terlihat, klik menu tiga titik (⋮) di Chrome → pilih Simpan dan bagikan → Instal FIEZEL.

Ingin langsung mencoba tanpa menginstal?

Anda bisa langsung mengakses seluruh fitur belajar FIEZEL melalui browser tanpa instalasi.

BANTUAN TEKNIS

Pertanyaan yang Sering Muncul

Menu install tidak muncul di browser?

Pastikan Anda membuka tautan resmi dengan protokol HTTPS (https://fiezel.my.id/app/). Di iPhone/iPad, pastikan memakai Safari. Di Android, gunakan Google Chrome.

Apa perbedaan antara versi APK dan Web App (PWA)?

Versi APK Android adalah aplikasi paket utuh yang terpasang di sistem Android. Versi Web App (PWA) berjalan melalui mesin peramban modern yang hemat memori tanpa perlu mengunduh file besar. Keduanya memiliki materi pembelajaran dan kecerdasan adaptif Braincore yang sama.

Bagaimana cara memperbarui aplikasi?

Versi Web App (PWA) otomatis diperbarui setiap kali Anda terhubung ke internet saat membuka aplikasi. Untuk versi APK Android, Anda dapat mengunduh pembaruan rilis terbaru dari halaman resmi ini.

Platform pembelajaran bahasa adaptif dengan mesin kognitif Braincore.
