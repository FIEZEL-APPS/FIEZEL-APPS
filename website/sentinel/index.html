Cara Kerja

Setup 3 Langkah, Selesai

1
Buat Token di Dashboard
Buka dashboard, klik "Setup Perangkat Baru", beri nama HP-mu. Sistem otomatis membuat Device ID dan Owner Token unik. Simpan token ini — kamu butuhkan untuk login.
2
Pindai QR di HP yang Dilindungi
QR code akan muncul setelah setup. Pindai dari HP tersebut, halaman terbuka. Klik "Tambahkan ke Layar Utama" (iOS) atau "Pasang aplikasi" (Android). Selesai — ikon kalkulator muncul di Home Screen.
3
Monitor dari Mana Pun
Jika HP hilang, buka dashboard dari browser mana pun, masuk dengan Device ID + Owner Token. Lihat peta lokasi real-time, kirim alarm, atau minta foto pelaku — tanpa perlu PC menyala.

FAQ

Pertanyaan Umum

Apakah harus install aplikasi?
Tidak. Ghost Sentinel adalah PWA (Progressive Web App). Kamu hanya perlu membuka URL di browser, lalu tambahkan ke Home Screen. Tidak perlu App Store atau Play Store.
Apakah maling bisa tahu kalau HP dilacak?
Sangat sulit. Tampilan kalkulator terlihat persis seperti kalkulator biasa. Transmisi data berjalan di balik layar, tidak ada notifikasi atau indikator yang terlihat.
Apa yang terjadi jika maling mematikan HP?
Data terakhir sebelum HP mati sudah tersimpan di cloud. Saat HP dinyalakan kembali dan terhubung internet, transmisi otomatis dilanjutkan.
Apakah menguras baterai?
Minimal. Tracker hanya aktif saat kalkulator dibuka, atau mengirim beacon kecil setiap 60 detik saat berjalan di background. Konsumsi baterai jauh lebih kecil dari aplikasi chat biasa.
Data disimpan di mana?
Di Cloudflare KV (edge network global). Data disimpan 60 hari dan hanya bisa diakses dengan Owner Token milikmu. Kami tidak menyimpan token — jika hilang, tidak bisa dipulihkan.
Apakah legal?
Ya, untuk perangkat yang kamu miliki. Melacak HP sendiri yang dicuri adalah hak pemilik dan diakui sebagai bukti oleh penegak hukum. Jangan gunakan untuk melacak HP orang lain tanpa izin.
