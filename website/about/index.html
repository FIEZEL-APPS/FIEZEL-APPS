About FIEZEL — Adaptive Language Platform & Braincore Engine

What is FIEZEL?

FIEZEL is an adaptive language learning platform and educational initiative founded in Banda Aceh, Indonesia. Powered by the client-side Braincore cognitive engine (< 0.2 ms latency, Rp 0 API cost per practice question, 0% grammatical hallucination), FIEZEL delivers high-yield English learning, Kawan Bicara AI voice studio, and the KelasKu teacher workspace for schools.

Origin Story & Banda Aceh Engineering Roots

FIEZEL was founded in Banda Aceh, Indonesia, by Fitra Rusdiawan (Founder & Product Lead) and co-engineered with Athar Rayyan Muhammad, S.Kom. (Technical Lead & System Auditor, Master's candidate in Artificial Intelligence at Universitas Syiah Kuala - USK).

The platform was born from Fitra's personal struggle preparing for the IELTS exam (targeting band 5.0–5.5) required for a 2-year vocational education and training (VET) diploma in Australia. In regional Indonesia, formal English test preparation often costs Rp 3,000,000 to Rp 5,000,000—a prohibitive barrier for vocational aspirants. Mainstream language apps either burned costly cloud LLM tokens while hallucinating grammar rules, or spoon-fed correct answers immediately after a mistake without explaining syntax.

To solve this, Fitra teamed up with AI researcher Athar Rayyan Muhammad to build Braincore: an explainable, client-side cognitive engine that provides multi-tiered Socratic hints, diagnoses misconceptions locally, and costs Rp 0 in cloud API overhead per question.

How FIEZEL's Adaptive Learning Works: Braincore

At the heart of FIEZEL is Braincore, a proprietary client-side adaptive learning engine. Rather than relying on generic cloud LLM wrappers that suffer from hallucinations, high latency, and continuous API costs, Braincore executes deterministic cognitive modeling directly in the learner's browser:

  1. Sub-Millisecond Speed (< 0.2 ms) & Rp 0 API Cost: Grammar evaluations and mastery updates compute locally in browser memory in under 0.2 milliseconds, completely eliminating cloud API token overhead per question.
  2. 0% Grammatical Hallucination: Responses are validated using deterministic Abstract Syntax Tree (AST) checking and vetted diagnostic matrices, guaranteeing that students are never taught hallucinated grammatical rules.
  3. Two-Tier Socratic Hint Scaffolding: When a learner answers incorrectly, Braincore does not spoil or leak the answer key. Instead, Tier 1 provides a conceptual hint targeting the underlying syntax rule. If the second attempt fails, Tier 2 explains why the specific chosen distractor was incorrect.
  4. Bayesian Knowledge Tracing (BKT) & IRT 3PL: Braincore separates genuine competency from lucky guesses ($c$) or careless slips ($s$), calculating real-time latent ability ($\theta$) across grammar points.
  5. FSRS-Lite Spaced Repetition Scheduling: Items answered incorrectly re-emerge dynamically across upcoming practice cycles based on scientifically calibrated memory decay curves.
  6. Multi-Exam Psychometric Readiness: Braincore's cognitive architecture extends beyond general English to high-stakes examinations including IELTS, TOEFL, CPNS/CASN, BUMN, and UTBK-SNBT.

PWA Architecture & Offline Capability

FIEZEL is engineered as a modern Progressive Web App (PWA):

  • Zero App Store Friction: Add directly to the home screen from Chrome (Android/Desktop) or Safari (iOS). No 100MB store downloads.
  • Offline-Capable Learning: After installation, core lesson texts, vocabulary sets, reading exercises, and Braincore client-side mastery calculations function without an active internet connection.
  • Private by Design: Learning records and mastery matrices are stored locally on the device (IndexedDB/localStorage). No invasive tracking profile is required to practice.

Teacher Layer: KelasKu by FIEZEL

KelasKu is FIEZEL's dedicated classroom workspace for teachers, tutors, and schools. It bridges independent student practice with classroom instruction while solving modern educational pain points:

  • No-Phone Classroom Mode: To support schools with strict smartphone bans, KelasKu features a 5-minute interactive projector quiz mode and 1-click printable A4 PDF worksheets with QR answer keys.
  • Frictionless Class Codes: Teachers generate 6-character room codes (e.g., FZ-ABCDEF). Students connect instantly without needing email addresses or social logins.
  • Automated Grading & Competency Heatmaps: Homework assignments mapped to curriculum chapters are evaluated automatically, visualizing collective misconceptions and suggesting peer study pairs.
  • Automated e-Rapor KKTP Drafting: Teachers can generate exportable narrative achievement reports aligned with Kurikulum Merdeka standards in seconds.

Kawan Bicara AI: On-Demand Voice Studio

For speaking fluency, FIEZEL provides Kawan Bicara AI, an on-demand conversation partner designed to solve the conversational interruption dilemma of generic voice assistants:

  • Zero-Friction Teleprompter: Unlike blind-audio chatbots that require preexisting fluency, FIEZEL displays real-time on-screen native translations in Indonesian/Thai directly below the transcript, eliminating awkward pauses to ask "what does that mean?".
  • Phonetic & Romaji Guides: Japanese Kanji expressions are paired with Ruby furigana and Hepburn romaji, allowing beginners who cannot read kanji to speak naturally from their first call.
  • Beginner Answer Assistant: Generates 3 contextual native reply options (Short, Natural, and +Follow-up) with a one-tap audio preview button so learners can listen before speaking aloud.
  • Ultra-Low Latency Voice Pipeline: Groq Whisper STT (<300 ms), context-bounded reasoning with pedagogical guardrails, and crisp natural Edge-TTS audio.
