# FIEZEL — Information Architecture

## Current structure (as measured)

15 routes in `VALID_VIEWS`, reached through 5 bottom-nav tabs, 1 topbar action, a launch
grid on Home, and 3 routes with no persistent entry point at all.

```
Boot
 └─ Splash ──► Onboarding (6 steps) ──► Guided tour ──► Notification gate ──► Auth gate ──► HOME
                                                                                             │
    ┌──────────────── bottom nav (5) ────────────────┐                                       │
    │                                                │                                       │
  home        vocab       grammar      reading     progress ("Peta")                         │
    │           │            │            │            │                                     │
    │           │            │            │            └─ tabs: Ringkasan · Analisis ·       │
    │           │            │            │                     Adaptive Engine · K…         │
    │           │            │            │                                                  │
    │           │            └─ 29 lesson rows ──► lesson intro ──► QUIZ (25) ──► completion │
    │           │                                                                            │
    │           └─ quiz (12) · flashcards · review                                           │
    │                                                                                        │
    └─ launch grid ──► library · classroom(locked) · skills ──► listening · speaking · writing
                                                                                             │
  topbar ──► ask/search · settings modal · level panel                                       │
  no persistent entry ──► test (placement) · online                                          │
```

### Problems this shape creates

1. **Two navigation systems disagree about what matters.** The bottom nav promotes
   Vocab / Grammar / Reading; the Home launch grid promotes Vocabulary / Grammar /
   Perpustakaan / Classroom; Skills Lab (which owns Listening, Speaking, Writing) is in
   neither. Listening, Speaking and Writing — three of the six core skills — are two taps
   deep behind a card that is not on the nav.
2. **`skills` is a router, not a destination.** It exists only to forward to
   `listening` / `speaking` / `writing`, which are themselves routes. Three ways to reach
   the same three screens.
3. **`ask` and `search` render the same view** (`askView()`), from two different entries.
4. **`test` has no home.** Placement is reachable from onboarding and from contextual
   prompts, but a learner who skipped it and later wants it has to find it.
5. **Depth is inverted.** The fastest-to-reach screen (Home) is the one the learner needs
   least often once they have a habit; the exercise — the reason the product exists — is
   3–4 taps deep (nav → hub → lesson intro → start).

## Target structure

The change is **not** adding or removing routes. Every route survives. What changes is
which of them are *promoted*, and how many decisions sit between opening the app and
answering a question.

```
HOME  ─ one primary: "continue" ─────────────────────────► QUIZ
  │                                                          ▲
  │  secondary: choose a different focus                     │
  ├── Grammar ─► path (resume-anchored) ──────────────────────┤
  ├── Vocab ────────────────────────────────────────────────  ┤
  ├── Reading ─────────────────────────────────────────────── ┤
  ├── Skills ─► Listening · Speaking · Writing ─────────────── ┘
  │
  │  tertiary (browse / reference)
  ├── Library · Classroom
  └── Progress ─► Ringkasan · Analisis · Engine · Kesehatan

  always available, never competing: Ask · Search · Settings · Level
```

### Rules

**R1 — One primary action per screen.** Every screen answers "what now?" with exactly one
visually dominant control. Everything else is secondary by construction, not by hope.

**R2 — The exercise is at most two taps from cold open.** Home's primary CTA resumes the
current lesson directly. The hub is the *alternative* path, not the default one.

**R3 — Hubs are resume-anchored, not catalogue-anchored.** A hub opens at "where you are",
with the rest of the curriculum reachable but not pre-rendered. A 29-item list is a
catalogue; a learner needs a position.

**R4 — Sections scale with their content.** A section with nothing in it is a row, not a
card. (Implemented as `foldCard()` — see `08-COMPONENTS.md`.)

**R5 — Global settings live in one place.** `Level belajar · Ganti` is a global preference;
it belongs in Settings plus one contextual affordance, not as a card on seven screens.

**R6 — Progressive disclosure has exactly one component.** `.home-fold`. Not a fold here,
an accordion there, and a `?` popover somewhere else.
