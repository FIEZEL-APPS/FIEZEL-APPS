## 8. Regression watchlist

Areas historically fragile in this repo — check explicitly after any UI change:

1. **Scene/phase styling** — the P0 came from a phase override outliving its ground.
   Any new `body.scene-*` rule needs the phase invariant to pass.
2. **Boot chain** — splash critical CSS is duplicated in `index.html` and gate-compared.
3. **Mascot stage flags** — `fz-stage-home` / `-sl` / `-map` / `-hub` / `-writing` suppress
   the floating bubble on screens with controls near the bottom. A new screen with a
   bottom CTA needs its flag.
4. **MEASURE mode** — placement / skip-level / unlock gates must never reveal per-question
   verdicts or explanations.
5. **Golden baseline** — any student-visible Indonesian string change turns it red by
   design. That is correct; regenerate deliberately, never reflexively.
