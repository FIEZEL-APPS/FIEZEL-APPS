📥 Unduh File Profil (.mobileconfig)
Langkah Pasang di iPhone (Sangat Mudah):
1. Buka Kamera iPhone → Arahkan ke QR Code di atas → Ketuk tautan → Ketuk "Izinkan" (Allow) saat muncul notifikasi Profil Diunduh.
2. Buka Pengaturan (Settings) iPhone → Ketuk menu "Profil Diunduh" di paling atas → Ketuk "Pasang" (Install).
