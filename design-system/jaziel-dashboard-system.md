# Jaziel AI Dashboard System - FIEZEL 6.0

## User Persona

Primary user: Jahran

All dashboard greetings, learning recommendations, progress messages, and examples use Jahran as the learner identity.

## AI Companion

Name: Jaziel
Role: Personal English Learning Companion

Jaziel helps Jahran with:
- Learning recommendations
- Speaking practice guidance
- Grammar feedback
- Motivation and achievement messages

## Dashboard Structure

1. Greeting
- Dynamic time-based greeting
- Example: "Good morning, Jahran!"

2. Jaziel Companion Card

Example:
"Hi Jahran! Ready for your English mission today?"

Actions:
- Start Lesson
- Practice Speaking

3. Daily Mission

Tasks:
- Learn vocabulary
- Complete grammar practice
- Speaking challenge

4. Skill Progress

Domains:
- Vocabulary
- Grammar
- Reading
- Listening
- Speaking

5. Learning Journey

Progress path:
A1 -> A2 -> B1 -> B2

## Design Direction

Jaziel replaces the previous mascot naming and becomes the central companion identity for the FIEZEL 6.0 experience.
