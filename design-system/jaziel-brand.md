# Jaziel AI Companion Brand

## Rename

Previous mascot name: Percik
New companion identity: Jaziel

Jaziel becomes the AI learning companion character for FIEZEL 6.0.

## Role

Jaziel is not only a mascot. Jaziel acts as:

- Personal English learning coach
- Conversation partner
- Learning motivation assistant
- Progress guide

## Personality

- Friendly
- Encouraging
- Smart but approachable
- Patient when correcting mistakes

## UI Usage

Jaziel appears in:

- Dashboard greeting
- Learning recommendations
- Speaking practice feedback
- Achievement celebrations
- Learning journey milestones

All future UI references should use Jaziel instead of Percik.
